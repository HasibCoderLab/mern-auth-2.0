# 🚀 MERN-Auth 2.0

![Version](https://img.shields.io/badge/version-2.0-blue.svg)
![Node](https://img.shields.io/badge/Node.js-Backend-green)
![MongoDB](https://img.shields.io/badge/Database-MongoDB-brightgreen)
![JWT](https://img.shields.io/badge/Auth-JWT-orange)

A secure **MERN Authentication System** built with **Node.js, Express, MongoDB, JWT, and Cookies**.  
This project focuses on **authentication best practices** and **security-first backend design**.

---


## 📦 Tech Stack

### Backend
- **Node.js**
- **Express.js**
- **MongoDB (Mongoose)**
- **JWT (jsonwebtoken)**
- **Cookie Parser**
- **bcryptjs (Password Hashing)**
- **Nodemailer (Email Service)**
- **CORS**
- **dotenv**

### Frontend (Auth Support)
- **Axios**
- **React Router**
- **React Toastify**

---

## ⚙️ Installation & Setup

### 1️⃣ Initialize Node Project
```bash
npm init -y
```
2️⃣ Install Core Backend Packages
```bash
npm install express mongoose dotenv cors cookie-parser
```
3️⃣ Install Authentication & Security Packages
```bash
npm install jsonwebtoken bcryptjs
```

4️⃣ Install Email Service
```bash
 npm install nodemailer
```
5️⃣ Install Dev Dependency (Auto Restart)
```bash
npm install nodemon --save-dev
```
🌐 Frontend Helper Packages
```
npm install axios react-router-dom react-toastify
```
